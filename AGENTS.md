# Agent notes

## Git

- Commit and push straight to the default branch, `bepinex5`, on `origin` (TianCal/HsMod). Don't create feature branches or pull requests unless asked.
- `upstream` is Pik-4/HsMod. Don't push there.

## Windows launcher

- `tools/windows/launch_hsmod.ps1` is the source of the launcher installed at `C:\Program Files (x86)\Hearthstone\launch_hsmod.ps1` on the Windows PC. The desktop shortcut runs it. After changing one copy, update the other.
